## 🎓 关键设计决策

### 1. Event Sourcing 作为事实来源
- 所有状态变化都记录为事件
- 支持完整的历史追踪和恢复
- 便于审计和调试

### 2. 不可变 Checkpoint
- Checkpoint 创建后永不修改
- 保证恢复点的完整性和一致性
- 支持多版本管理

### 3. 副作用核查流程
- 5 种副作用状态分类
- 每种状态有明确的恢复策略
- 避免盲目重放外部操作

### 4. 版本追踪
- Runtime、Workflow、Agent、工具集版本独立追踪
- 支持版本升级后的兼容恢复
- 便于滚动升级
