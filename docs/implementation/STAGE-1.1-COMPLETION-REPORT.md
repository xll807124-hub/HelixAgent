### 关键设计决策

1. **事件溯源架构**：所有状态变更通过追加式事件记录
2. **状态投影分离**：运行时和投影分离，提高可维护性
3. **RBAC + Policy Gateway**：两层策略决策，安全且灵活
4. **Checkpoint 恢复**：支持从任意检查点恢复
5. **Trace 传播**：完整审计链路追踪
