## 改动

- 完整定义使用版本化指纹，保留 Schema 扩展和原始工具元数据，覆盖平台风险/能力；非JSON值拒绝。
- 批准绑定组织、连接器配置/身份修订、工具定义和清单代次；可信回调、有效期和审计共同控制发布。旧无作用域批准仅作历史。
- 发现先逐提供方检查；协议入口和 v2 执行器拒绝未批准工具，凭据等待后再次核对批准 ID 和代次。
- 清单/定义/配置变更使整代批准失效，活动连接器进入复审并联动凭据撤销。部分清单、刷新失败和迟到结果不恢复旧缓存。
- 选定工具明确批准并完成复审后，恢复仍检查签名与凭据撤销。普通暂停/恢复保留定义批准，在途请求继续由凭据代次阻断。
- 审批回调和外部撤销在锁外执行。批准/复审审计失败不发布许可；停止动作不因审计失败撤回。已完成远端执行的审计异常仅记录类型，不假称撤销已发生的副作用。

触达 REQ-SEC-007，复用前项 SEC-005 联动。无 Runtime/Event 共享契约变更、无新增依赖或密钥。关键实现：[治理编排](../../src/security/mcp_connector_governance/registry/tool_governance.py)、[定义模型](../../src/security/mcp_connector_governance/models/tool_schema.py)、[协议入口](../../src/security/mcp_connector_governance/protocol/mcp_handler.py)、[执行器](../../src/security/mcp_connector_governance/execution/tool_executor_v2.py)、[专项测试](../../tests/test_mcp_tool_approval_schema.py)。完整文件、当前行数和内容指纹见 [JSON](./sec007-tool-approval-schema-2026-10-29.json)；保留原有未提交实现，不把整份 Git 差异当成本轮新增。
